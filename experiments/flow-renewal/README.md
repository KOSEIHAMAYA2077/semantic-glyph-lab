# F1: 文字の配置を更新して、長時間の引き伸ばしを抑える

2026-09-30 / 独立した研究比較。元の試遊版とソースは変更しない。

**結果: 文字の引き伸ばしは抑えられた。ただし画像の交替では文字が二重になり、位置の交替では流れの忠実さを失う。本体へはまだ採用せず、比較できる別版として保存する。** 次は、同じ文字の中心を運び、字形を曲面の小さな領域に保つF2と比較する。大きな形状生成モデルの取得・実行は今回行っていない。

## 試す

リポジトリ内で依存を用意して、`node experiments/flow-renewal/serve.mjs`。専用の [比較画面](http://127.0.0.1:4192/src/renewed-flow/preview.html?mode=coordinates) が開ける。球・花瓶・生成じょうろ、従来の流れ・画像の交替・位置の交替を選べる。ドラッグで回転、停止・再開。方式を替えても計算時刻は変わらない。固定した人工44書記素を使う比較画面で、文章の入力機能は含めない。

4192を使用し、旧4173・4183は変更しない。この入口は研究用の開発サーバーで、既存の配布用ビルドには追加していない。測定を安定させるためファイル監視とHMRを切っているので、**ソースを変更したらこの専用サーバーを再起動する**。

## 比較した方法

速度場は既存の[2D流体実験](../fluid-surface/README.md)と同じ。128²格子、dt=1/60秒、圧力40反復、seed 20260930、力0.4、明示4点補間、一次の座標移流。三方向から同じ立体へ投影する。曲面固有の流体計算ではない。

一つの速度場で、従来の累積変位と、更新用の変位A/Bを同時に運ぶ。Aを60秒ごと、Bを30秒ずらして60秒ごとに初期化する。Aの重みは `0.5 - 0.5 cos(2πt/60)`、Bは残り。初期化する側の重みが0になる整数ステップで、両方の保存先を初期化する。開始時には両方とも初期配置のため、最初の30秒は過渡状態になる。

| 方式 | 内容 | 今回見えた制限 |
|---|---|---|
| 従来の流れ | 一つの変位を時間制限なく積み重ねる | 徐々に伸び、10分相当では面の文字が線になる |
| 文字画像を混ぜる | A/Bでそれぞれ文字を描き、画像を混ぜる | 各字の伸びは小さいが、重みが半々の時に二重像が出る |
| 位置を混ぜる | A/Bの変位を混ぜ、一度だけ文字画像を参照する | 二重像を避けられるが、更新による速度が加わり、元の流体と同じ移動にはならない。流れの巻戻り・往復を生じ得る |

位置を混ぜる方式の時間微分には、元の移流に加えて `w'(t) × (A−B)` が入る。この見せ方を、同じ文字が流体に従ってずっと循環する方式とは呼ばない。いずれも[研究方針の応用案](../../research/roadmap-20260930.md)であり、先行論文の再現ではない。

## 固定刻みの結果

[comparison-v1/results.json](comparison-v1/results.json) は615秒、36,900ステップまでの比較。**615秒の実時間放置や30分の動作確認ではない。** 15秒刻みと、30/600秒の初期化前後1ステップを含む46時点を記録。600秒と同じ片側表示の位相だけでなく、315/585/615秒など両方が半々になる時刻も撮影した。

| 計算時刻 | 従来: 伸縮指標p95 | A/B: 伸縮指標p95 | 従来の反転セル | A/Bの反転セル |
|---|---:|---:|---:|
| 300秒 | 3.969 | 1.000 / 1.256 | 0 | 0 / 0 |
| 315秒 | 4.129 | 1.124 / 1.382 | 10 | 0 / 0 |
| 600秒 | 13.025 | 1.000 / 1.257 | 358 | 0 / 0 |
| 615秒 | 13.728 | 1.125 / 1.388 | 412 | 0 / 0 |

伸縮指標はUV逆写像の微分の特異値から `max(σmax, 1/σmin)` を計算したもの。1は等長。文字の読字率や、3D面の被覆率ではない。A/Bはそれぞれの写像の値で、**画像混合や座標混合後の最終表示の指標ではない**。非正のJacobianセルを反転として数えた。全16,384セル。

採取した全時点でA/Bの反転セルは0、伸縮指標p95の最大は1.507。ただし毎ステップを調べた最大値や、長時間・別seedでの保証ではない。従来方式の600秒では、以前の失敗記録と同じ358反転セル、Jacobian最小−1.266・最大7.873を再現した。

静止した球・花瓶・人工生成じょうろで、位置の混合では面の文字が残ることを担当エージェントが画像確認した。読字率を測った人間参加者の評価ではない。斜面の三平面投影による混ざり、字の向き、同一文字の軌跡は未解決。母体の変形との同時比較、新規文字の追記、一般PCの動作も今回の対象外。

## 時間変化と負荷

[初期化の直前・直後の画像差](reset-differences-v1.json)は、球の固定領域で測ったRGB平均絶対差。600秒の画像混合は直前0.0904・直後0.0913、位置混合は0.0902・0.0912（0〜255）。検査した境界で急な差の増加は見られないが、知覚上のちらつきが無いことの証明ではない。

[motion-v2/results.json](motion-v2/results.json)には、45秒へ固定刻みで進めてから約18秒の実時間動作を撮った2動画を保存した。最初の早送りと、60秒の更新を含む実時間部分を区別する。録画の負荷があるため性能値の比較には使わない。

- [文字画像を混ぜる動画](motion-v2/page@ccbd5b3e6be5052ee61a083349a843ea.webm)
- [位置を混ぜる動画](motion-v2/page@c75f50bd60dc8266a8aa26869416dc82.webm)

本比較の球で、準備30フレーム後の240フレームは3表示方式ともrAF間隔のmedian/p95が約16.7msだった。Apple M5・Chrome・ANGLE Metalでの表示間隔で、GPU時間や一般PCの性能ではない。全方式で従来マップとA/Bの3写像を計算したままなので、表示方式の比較であり、従来実装に対する追加費用の厳密な測定ではない。追加の128²・RGBA32F保存先4枚は約1MiB。CPU/GPU負荷と電池の長時間評価は残る。

## 検証と失敗の保存

- 位相境界と不可視時の初期化、平行移動、面積が同じでも伸びるせん断、反転・非有限値を7テストで確認。既存分を含む465テストと型検査・既存2入口ビルドが通過。新しい研究入口は開発サーバーで確認。
- ブラウザで方式切替、停止・再開、初期化、同時刻の形切替を操作。比較実行でJS/console/GLエラー、外部リクエスト0。従来と新方式の1秒後の速度・変位の先頭サンプルが一致し、再初期化でも同じ値になった。全フィールドのビット一致の検査ではない。
- 初回長時間比較のソースはcommit `f37beb2`と出力内SHA256に対応する。結果を上書きせず保存。その後、既定で使わない補正移流オプションをA/Bにも同じ方法で適用し、診断後の表示時計の初期化を修正した。既定の一次移流の式は変えていない。
- [final-smoke-v1](final-smoke-v1/results.json)は失敗。監視を切った専用サーバーが修正前コードを保持していた。専用サーバーだけを再起動し、[v2](final-smoke-v2/results.json)で一次/補正の初期マップ指標一致と、診断後の両時計の初期化を確認した。修正後コードで長時間比較を再実行したとはしない。
- [motion-v1](motion-v1/results.json)は動画0件。録画用FFmpegが未取得で開始前に停止した記録。成功とは扱わない。隔離した環境へ公式配布を取得し、v2で2動画を保存した。

## 採否と次

画像の混合をそのまま既定にする案は二重像のため見送る。位置の混合は字形を保つ見せ方として比較用に残すが、同一の文字が連続的に流れる解決とは採用しない。次はF2の曲面パッチを、今回の位置混合と同じ人工文・密度で比較する。複雑な3D生成を増やす前に、字形の維持と流れの連続性の両立を確認する。

球・花瓶は既存の手続き形状。じょうろは[既存の人工生成物と来歴](../../public/end-to-end-models/manifest.json)を読むだけで、原本を変更していない。**Powered by Stability AI**。ユーザーの本文・参考画像・書籍・モデル重みは追加していない。
